# Winnow Notes

A second brain over your Obsidian vault. Winnow reads what you write and save, proposes the ideas worth keeping, and lets you decide in Obsidian what becomes permanent.

## Install in Claude (Cowork)

1. In the Claude desktop app open **Customize -> Plugins**.
2. Select **Add marketplace** and paste `https://github.com/seansukonnik-ctrl/winnow-notes`.
3. Find **winnow** in the list and select **Install**.

In Claude Code: `/plugin marketplace add seansukonnik-ctrl/winnow-notes`, then `/plugin install winnow@winnow-notes`.

Winnow also needs its Obsidian plugin and a vault set up for it; the starter vault download handles both.
